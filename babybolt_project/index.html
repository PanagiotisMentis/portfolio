Baby BOLT UART to CAN Adapter PCB

STM32 • Altium Designer

Overview

This project is just now getting started. Currently, the Baby BOLT electric motorcycle has a Battery Management System (BMS) that outputs UART telemetry. This adapter PCB will use an STM32 IC to put the UART input telemetry to CAN for the existing bike dashboard, which takes CAN data.

Hardware Components & Tools

STM32 Altium Designer Rust C CAN Protocol UART Protocol

Implementation & Technical Challenges

The adapter PCB must fit in a confined space next to the BMS to avoid interfering with other bike components. It must also run on appropriate power from the BMS.
